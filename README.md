## 个人简介

我是一名专注于 Web 开发、交互体验与游戏原型设计的开发者。

我喜欢把创意转化为可用的产品，把界面做得清晰、稳定且有辨识度，同时也持续探索更有表达力的数字体验。

## 核心能力

- 前端开发：HTML / CSS / JavaScript
- 后端与工具链：Node.js / Python / Tauri
- UI/UX 与原型：交互逻辑、界面结构、视觉优化
- 游戏方向：机制设计、小型游戏原型、实验性项目

## 当前方向

- 搭建实用型 Web 体验
- 开发交互式原型和小型游戏
- 优化界面结构与创意表达
